# SokoGH

Ghana marketplace website — Phase 1 visual prototype, connected into one real project
with working navigation between pages.

## Pages
- `/` — Home
- `/category` — Category browse + filters
- `/listing` — Listing detail
- `/auth` — Sign in / Create account
- `/post-ad` — Post an Ad (4-step form)

## Status
Design/UI only. No real backend, database, login, or photo upload yet — those come in
later phases. All listing data on these pages is placeholder/fake.

## Running this locally (optional — not required to deploy)
```
npm install
npm run dev
```
